# Applications

Applications Android de **visma**, à installer directement depuis ce dépôt.

## Platine Paris

Marcher dans Paris « complète » la ville petit à petit : chaque balade colorie les cellules de 100 m traversées,
fait progresser les 80 quartiers, découvre les stations de métro, musées et monuments croisés en chemin, et
nourrit missions, trophées, rangs et statistiques. Mode compétitif entre amis en option.

### ⬇️ [Télécharger Platine Paris (APK, 77 Mo)](https://github.com/visma/applications/releases/latest/download/PlatineParis.apk)

- Le lien donne toujours la dernière version ; date, nouveautés et empreinte SHA-256 de chaque version :
  [page des versions](https://github.com/visma/applications/releases)
- Android 8 ou plus récent

### Installation

1. Ouvrir le lien ci-dessus **depuis le téléphone** : le fichier se télécharge.
2. Ouvrir le fichier téléchargé (notification ou dossier *Téléchargements*).
3. Android demande d'autoriser l'installation d'applications depuis cette source (le navigateur ou l'appli
   *Fichiers*) : accepter, puis revenir en arrière et toucher **Installer**.
4. Au premier lancement, un écran de bienvenue présente l'application et propose d'activer le podomètre.
   La **localisation** et les **notifications** sont demandées au départ de la première balade.

Pour mettre à jour : télécharger et installer la nouvelle version par-dessus, les balades sont conservées.

> L'application n'est pas sur le Play Store : Android peut afficher un avertissement de sécurité, c'est normal pour
> une application installée hors du Play Store.
